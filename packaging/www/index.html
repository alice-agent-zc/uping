uping is running

This is the default page from the Debian package. The service is bound to loopback only and serves a certificate signed by uping's own CA.

Trust that CA once:

curl --cacert /var/lib/uping/internal/ca/root.crt https://localhost:8443/

Then replace /etc/uping/config.toml with your domains and run sudo systemctl restart uping. See man uping and /usr/share/doc/uping/.
